Inside the model

Token

A chunk of text the model reads or writes: a word, part of a word or a symbol. Models see a list of token IDs, not letters.

Inside the model

Embedding

Turning each token into a long list of numbers (a vector). Words with similar meanings end up with similar vectors, close together in space.

Inside the model

Residual stream

The model's running working memory. A token's vector flows through all the layers; each attention and MLP layer reads it and adds its output back, so information builds up instead of being overwritten. Interpretability tools mostly read from here.

Inside the model

Attention

How a token gathers information from earlier tokens. For “it”, the model scores how relevant each earlier word is (here, “cat”), then mixes in their information weighted by those scores.

Inside the model

Attention head

One of many attention mechanisms running side by side in a layer. Each learns its own pattern of what to look at; the grids show which earlier token (column) each token (row) attends to.

Inside the model

MLP layer

The other half of each transformer layer. It works on each token on its own, expanding into many neurons and back. It's where much factual knowledge seems to be stored, like “the Eiffel Tower is in Paris”.

Inside the model

Logits & next-token prediction

At the end, the model scores every possible next token (logits) and turns the scores into probabilities. It picks one, adds it to the text and repeats. That's all generation is.

Interpretability

Activations

The intermediate numbers a model produces while processing an input. Weights are fixed after training; activations change with every input. They're what probes and SAEs read.

Interpretability

Feature

A concept the model represents, usually as a direction in activation space. The more an input is about cats, the further its activations point along the “cat” direction.

Interpretability

Superposition

Models represent more features than they have dimensions by overlapping them at angles. It's efficient, but it's why single neurons are messy and hard to read.

Interpretability

Polysemantic neuron

One neuron that fires for several unrelated things. A side effect of superposition, and the reason you can't just read a model neuron by neuron.

Interpretability

Sparse autoencoder (SAE)

A tool that rewrites dense activations as many possible features with only a few switched on, then checks it can rebuild the original. The switched-on ones are often readable concepts.

Interpretability

Probe

A simple classifier trained on activations to detect one property, e.g. “is the model making this up?”. If a straight line separates the cases, the model represents that property.

Interpretability

Circuit

A small set of features and connections across layers that together carry out one behaviour, like finding the right name to repeat. Finding circuits is the “basic science” goal.

Interpretability

Steering

Adding or subtracting a feature direction in the residual stream to change what the model does. If it works, it's good evidence the feature really means what we think.

Interpretability

Model organism

A model deliberately trained to show a failure, like a hidden goal or a sleeper-agent backdoor, so researchers can test whether their detection methods find it.

Training

Pretraining

The first, most expensive stage: the model learns to predict the next token across trillions of tokens. It picks up language, facts and skills, dangerous ones included.

Training

Fine-tuning

Extra training on a small, targeted dataset. It's how assistants are made, and also how open-weight models can have their safety training removed.

Training

Reward model

A model trained to predict which answer humans would prefer. In RLHF it acts as the automatic “coach” that scores the assistant's answers.

Training

KL penalty

A cost for drifting too far from the original model during RL. It stops the model finding weird outputs that fool the reward model.

Training

Reward hacking

When the score keeps rising but the real goal gets worse, because the model found a loophole in how it's scored. Also called specification gaming.

Evals & control

Jailbreak

A prompt that tricks a model into doing something its safety training should stop, e.g. role-play, odd encodings or splitting a request into pieces.

Evals & control

Capability vs propensity

A capability eval asks whether a model is able to do something dangerous. A propensity eval asks whether it chooses to when it has the chance.

Evals & control

Scheming

A model secretly pursuing its own goals while appearing aligned. It behaves well while it thinks it's being watched and acts differently when it thinks it isn't.

Evals & control

Sandbagging

Deliberately performing worse on an evaluation, e.g. to avoid seeming dangerous. It makes capability evals underestimate what the model can really do.

Evals & control

Evaluation awareness

A model noticing it's being evaluated. If it then behaves better than usual, passing the eval tells you less about how it'll act for real.

Evals & control

Chain of thought (CoT)

The step-by-step reasoning a model writes before answering. Reading it is a cheap way to catch bad intentions, but only while the reasoning stays honest.

Evals & control

Trusted monitoring

An AI control setup: a weaker model we trust scores every action of a stronger model we don't, and sends the most suspicious ones to humans.
