# Technical AI Safety Atlas

An interactive study companion for BlueDot Impact's Technical AI Safety course.

- **Course atlas** (`index.html`): every unit as clickable diagrams, quizzes, flashcards, a visual glossary and draft exercise answers.
- **How transformers work** (`how-models-work.html`): follow a piece of text from tokens to a prediction, with an interactive demo at each step.
- **Architectures** (`architectures.html`): MLPs, CNNs, RNNs, transformer variants, mixture of experts, state-space and diffusion models, each with a small simulation.

All numbers in the simulations are hand-made toy examples that show the idea, not real model weights.
